# Visual audit — 31 October 2026

Compared the live homepage, About, Gallery, Video and Contact pages of [Jurij Drevenšek](https://www.jurij-drevensek.com/) with [Tine Ugrin](https://tine-ugrin.netlify.app/), using screenshots and rendered page state. Also reviewed Tine's Credits page.

| Step | Reference observation | Change to Tine |
| --- | --- | --- |
| 1. Homepage | Photograph, upper-left identity, upper-right menu. | Removed introductory text and duplicate calls to action. Reframed the portrait to show the head and shoulders. |
| 2. Navigation | Four primary links: About, Gallery, Video, Contact. | Matched the order and moved Credits into the supporting links. Removed the separate Casting control. |
| 3. Typography | White sans serif, restrained sizes and black active-menu highlight. | One active font family, regular body text, consistent fixed header and menu spacing. |
| 4. Background | Full-screen imagery carries the reference. | Kept the portrait on Home and plain charcoal on inner pages, following the request for simpler backgrounds. |
| 5. About | Central reading column; profile and CV resources. | One factual paragraph, languages and two resource links. Removed the slogan and repeated portrait. |
| 6. Gallery | Image grid without sales copy. | Removed numbers, promotional text and boxed expansion icons. Three desktop columns, two on phones. Portrait proportions preserve faces. |
| 7. Video | Direct thumbnail selection. | Two trailer thumbnails with title/year; removed the large stage, selector, repeated metadata and introductory copy. |
| 8. Credits | Supporting CV resources. | Replaced the filmstrip, counters and duplicate list with one seven-row table, PDF and print links. |
| 9. Contact | A narrow central contact area. | One enquiry label and a Filmmakers contact link. Removed duplicated profiles and casting/download controls. |
| 10. Mobile | Compact identity and menu. | Single-line identity, Menu/Close control, four page links, supporting profiles and language switch. |

Both languages retain separate page URLs. Photo attribution, original JPEGs, verified videos and PDF downloads remain accessible. The 404 page uses the same restrained typography and background.
